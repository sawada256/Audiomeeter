# Development rules

This is the canonical Audiomeeter v1 source repository. Commit every coherent source/documentation/configuration change to local Git with a descriptive message after relevant verification. Never commit generated apps/drivers, build caches, recordings, user settings, logs, credentials, or signing keys. Audiomeeter.app in /Applications is the active development/install target. Preserve the legacy app as a rollback copy and reuse its HAL drivers through explicit legacy UID compatibility unless migration is requested. Preserve the previous personal-use icon at the user’s request. Japanese mode retains original English labels; only originally Japanese copy is translated in English mode. Never publish or push without explicit authorization. Default language is Japanese; all app-owned UI and errors must also support English. Third-party plugin editors use their own localization.
