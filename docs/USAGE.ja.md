# 使い方

## 最初の音出し

1. [導入手順](INSTALL.ja.md)に従い本体と必要なHALを導入します。最初は音量を下げます。
2. A1の上部ボタンでスピーカー／オーディオインターフェースを選びます。
3. VAIO入力にAudiomeeter VAIO、AUX入力にAudiomeeter AUXを指定します。macOSの出力先をAudiomeeter VAIOにすると、PC音声がVAIOに入ります。
4. VAIOのA1を有効にします。入力と出力両方のMuteを解除し、フェーダーを調整します。
5. 通話・録音アプリの入力にAudiomeeter B1を選び、送信したい入力のB1を有効にします。

A1–A3は物理出力、B1/B2は仮想送出です。3つの物理入力とVAIO/AUXの計5入力を、各出力へ送れます。入力ソロ、ミュート、PAN、入力EQ／ダイナミクスも利用できます。

## DAWと内部ルーティング

DAWが入出力を同じデバイスに限定する場合、Audiomeeter VAIOを選ぶと、DAWからの再生はVAIOへ、DAWへの録音はB1から入ります。AUXは同様にB2と対になります。A1の物理出力自体を束ねる方式ではありません。別のStudio複合デバイスは不要です。

B1/B2はソフト内の入力ソースにも指定できます。戻した音を再び同じバスへ送るとフィードバックし得ます。DAWにPC音を取り込む場合、VAIO→B1を送り、DAWの戻りをAUX等へ分けるとループを避けやすくなります。

## インサートとサイドチェイン

INSERTを右クリックしてラックを開き、スキャン後、名称でARM64 VST3を選びます。通常のインストール場所のVST3を対象とし、製品自身のライセンス認証は別途必要です。物理入力・VAIO/AUX・出力バスにPRE/POSTエフェクトを置けます。

INSERT見出しの左クリックはチェーン全体のON/OFF、個々のプレビューの左クリックは個別バイパス、右クリックはそのエディターを開きます。ラックで追加・削除・並べ替え・編集を行います。これらの操作とサイドチェイン変更は音声を止めずに反映されます。

バイパスは2種類です。**簡易**（グレー表示）はプラグイン自身のVST3バイパスを使い（無い場合は遅延を合わせた原音）、遅延補正を変えません。**完全**（黒表示）はプラグインを経路から外し、その遅延も補正から除きます。クリック時の種類は「オーディオ設定 → 遅延補正」で選び、⌥クリックでもう一方を使います。ラックではMIDI入力（OFF／全チャンネル／CH指定）と、パラメーターのMIDI割り当ても設定できます。停止・処理落ちしたプラグインは既定で自動再起動します（1分に3回まで）。エディターを閉じてもエフェクト処理は続きます。プラグインのクラッシュやタイムアウトはバイパスへ移行しますが、CPU消費や危険なプラグインの動作を隔離するセキュリティ機構ではありません。

サイドチェインは未設定（無音）、入力、出力バスを選べます。非循環経路は同一ブロック、循環経路だけは前ブロックを使用します。1ブロックの時間は `1000 × frames / sampleRate` ms（48 kHz・256 framesで約5.33 ms）。設定の本流・サイドチェイン整列は時差を減らす代わりに本流を遅延します。プラグイン自体の先読み遅延は別です。

## 設定と遅延

オーディオ設定でサンプルレート、バッファ、チャンネル割り当て、遅延補正を設定します。「ハードウェア入力」（3〜5）と「物理出力バス」（A1–A3〜A1–A5）で画面の規模を変えられます。非表示にした入出力はデバイスを解放し、割り当ては保存されます。A1と同じ機器の入力・出力は、リングとクロック補正を通らずマスター処理内で直接読み書きされます。小さいバッファは低遅延ですがCPU負荷・途切れのリスクが上がります。デバイスが受け付ける範囲に制約があります。左右チャンネルは公開された入出力数から選びます。現在の割り当て保存はバス単位で、デバイス別プリセットではありません。

出力バス間整列を有効にすると、遅いプラグインに合わせ他バスにも遅延が加わります。独立したモニターを低遅延にしたい場合は無効にします。プラグイン遅延はサンプルとmsで確認できます。自動デバイス再起動とログイン時起動も設定できます。

## アプリ別trim、ホットキー、ミニミキサー

APPSは専用VAIO/AUX HALへ実際に音声を出しているクライアントを表示します。無音・非接続アプリが常に一覧に出るわけではありません。他社HALで同じ機能を保証しません。

設定で音量キー／ショートカットの対象と1回のdB変化量を指定します。音量キーの捕捉にはAudiomeeterへのアクセシビリティ許可が必要です。OS音量100%固定は仮想デバイス側の音量低下を防ぐ設定で、ミキサーフェーダーとは独立です。

ミニミキサーは常時表示／キー保持表示、表示位置、透明度を指定できます。10フェーダーそれぞれのメーター／フェーダー表示とアプリ別trimを選びます。音量・ミュートのホットキー操作後は最後の操作から約1.5秒表示します。ミュートはアイコンと灰色で表示。スクロール方向も設定で反転できます。

## レコーダーとプレーヤー

SRCで録音対象、FMTで形式を選びます。録音前のメーターで対象信号を確認し、録音開始／停止を操作します。Finderボタンから録音ファイルを表示できます。既定保存先は `~/Music/AudiomeeterRecordings`。停止後は書き込み完了まで待ってから次の録音を開始します。プレーヤーではファイルを開き送出先を指定します。巨大な再生ファイルはメモリ消費に注意してください。

## Macの出力先とデバイス音量

上部の「Mac出力」でアプリの音の出力先（コントロールセンターの「サウンド」と同じ設定）を選べます。「→ VAIO」はワンタップでAudiomeeter VAIOに切り替え、もう一度押すと直前の出力先に戻します。

A1〜A5のデバイス名の下のバーは、そのデバイスのmacOS出力音量です。この音量はデバイス（ドライバー）側で、Audiomeeterのミックスを含む全ての音に最後に掛かります。スピーカーを0%にしてからVAIOへ切り替え、A1をそのスピーカーにすると無音になるのはこのためです。B1/B2のOS音量はVAIO/AUXと共通で通常100%に維持されるため、フェーダーで調整します。

## マクロボタン・シーン・ルーティングマトリクス・診断

Menu → 「マクロボタンとシーン…」で、本家のMacro Buttonsに相当するボタンを作れます。動作は「押す（1回実行）」「トグル」「押している間ON」。トグルはグループ番号を付けるとラジオボタンとして動作します。スクリプト例: `Strip[0].A1 = 1; Strip[3].Mute = toggle; Bus[1].Gain -= 3; Scene = "配信"; Recorder.Record = 1; Button[2].State = 0`。番号は表示中の並び（ハードウェア入力→VAIO→AUX、A1〜→B1→B2）で0から数えます。各ボタンにはキーとMIDIを割り当てられます。

**シーン**は、ルーティング・音量・Mute/Solo・EQ・ダイナミクス等・INSERT状態をまとめて保存し、呼び出す範囲を項目ごとに選べます。デバイスとチャンネル割り当ては変更しません。シーンはボタン、マクロ、MIDIから呼び出せ、ボタンとシーンはJSONファイルへ書き出し・読み込みできます。

「ルーティングマトリクス…」は全入力×全出力の一覧で、クリックで接続を切り替えます。「診断…」には処理負荷、締切超過、各入出力の方式（直結／リング＋補正）、リングの不足・溢れ、クロック補正量（ppm）、経路の遅延、プラグインごとの処理時間・遅延ブロック・再起動回数、録音の欠落を表示します。

## MIDIコントローラー

「オーディオ設定 → MIDI」で、つまみ・フェーダー・ボタン・パッドを各チャンネルの操作に割り当てます。「＋ 割り当てを追加」で対象と操作を選び、「Learn」を押してから操作子を動かすと登録されます。フェーダーを右クリックして「MIDI Learn」を選ぶこともできます。

- 対象: 入力ストリップ（フェーダー、Mute/Solo、A1〜B2ルーティング、PAN、PAD X/Y、COMP/GATE、3バンドEQ）、出力バス（フェーダー、Mute、EQ、LIMIT）、レコーダー（録音、再生／一時停止、停止）、VST3パラメーター（一覧から選択、またはプラグイン画面で最後に動かしたもの）、マクロボタン、シーン呼出。
- メッセージ: CC、ノート、ピッチベンド（Mackie系14bitフェーダー）。接続中のすべてのMIDI入力を受け付けます。
- 値の形式: 絶対値、相対（1/127、2の補数）、相対（64中心）。ピックアップONの絶対値つまみは現在値に到達してから反映します。
- ボタン: 「押すたびに切替」または「値に追従（127=ON）」。
- MIDIフィードバック（モーターフェーダー・LEDへの送信）は未対応です。
