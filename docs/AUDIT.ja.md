# v1実装レビューと検証範囲（2026-10-11）

このレビューは静的点検、オフライン回帰テスト、ビルド、UI確認の結果です。「すべてのOS・機器・プラグインでバグがない」という保証ではありません。実機HALの入れ替え、管理者認証、スリープ／抜き差しの長時間実機試験は、普段使いの音声環境を変更しないため実施していません。

## 修正した問題

- **録音の上書き**：秒単位の同名ファイルを再作成し得たため、録音ファイル名にUUIDを追加。短時間で再録音しても前のデータを保持する回帰テストを追加。
- **録音停止時のUI待ち**：ディスク書き込み排出・ファイル終了を非同期化。終了処理中の新規録音を防止し、アプリ終了でも完了を待つ。並行した停止要求でも二重終了しないことを検証。
- **録音書き込みエラーの黙殺**：`ExtAudioFileWrite`のエラーを検出し、書き込みを停止して画面に表示。
- **無効な入力チャンネルの扱い**：選択した左右が両方なくなった場合にも、誤って1/2へ戻したり過去のデータを使わず、無音フレームを返す。
- **旧ペア選択との競合**：ペア単位の設定APIを使った場合、左右個別指定をクリアし、新設定が無視される状態を防止。
- **配布用インストーラー**：旧アプリを無条件に削除する方式を使わず、検証したステージングコピーとバックアップで更新。HALの途中失敗時は新規設置分も含めてロールバック。
- **製品識別と依存関係**：アプリ名／bundle ID／HAL名／設定保存先をAudiomeeterへ分離。HALごとに異なる固定factory UUIDを設定。JUCE取得コミットを固定し、ライセンス文を成果物へ同梱。
- **表示と言語**：旧READMEの完全互換・無欠陥・極小遅延等の未立証表現を除去。日本語初期値と英語切替を追加。元の文字列／データ保存用enum値を混同せず、表示時に翻訳。

## 確認した設計

- 音量キー捕捉はUIのrun loopと分離されたスレッド。対象は音量メディアキーに限定し、マウスクリックやドラッグを取得・破棄しない。
- メーター更新は個別ストアを監視し、メーター更新のたびにミキサー操作部全体を再描画しない。
- VST3は別プロセスで実行。遅延・ハング・終了時はレイテンシを保ったバイパス。同期IPC待ちをリアルタイム処理へ入れない。
- サイドチェインは非循環経路を同一ブロック、循環経路のみ履歴へ。入力のPDCと出力バス間同期は独立設定。
- 録音メーターは実際の録音タップと同じ処理後のstrip/busバッファのメーターを参照し、録音前にも表示。

## 公開前に残る問題・未検証条件

1. **権利整理は未完了**：AGPL/GPLの適用範囲は整備済み。ただし、BlackHole初期ソースの正確な由来、依存する全コンポーネントの確認、名称／外観の商標・誤認調査。既存アイコンは所有者によるAI生成オリジナルとの説明を記録し、配布用にも維持。名称・外観の商標等の確認は別途必要。MITのみで全体を配布できる状態ではありません。
2. **配布用署名・公証は未完了**：現在のローカル開発署名はDeveloper ID公証済みの一般配布物ではありません。HALとプラグインロードを含め、hardened runtime・エンタイトルメント・macOS許可を実機で検証する必要があります。
3. **実機の網羅性**：新Audiomeeter HALはこのMacに導入していません。UMC全出力の実測、複数USB機器、Bluetooth、スリープ／復帰、抜き差し、macOS 14/15/26それぞれでの実機試験が必要です。浮動小数点以外の特殊なストリーム形式も未検証です。
4. **任意プラグインの安全性**：別プロセスはクラッシュ影響を減らしますが、セキュリティサンドボックスではありません。プラグインによるファイル／ネットワークアクセス、メモリやCPUの大量消費まで封じる設計ではありません。多数の市販プラグインやライセンス管理方式は未網羅です。
5. **録音の異常系**：書き込みエラー表示は実装しましたが、実際のディスク満杯／取り外し、長時間録音の上限、電源断、リング容量超過の見える化は追加試験・改善対象です。再生ファイルはメモリに展開するため巨大ファイルに制約があります。
6. **多言語QA**：アプリのUI・説明・エラーは切替対象ですが、プラグインGUI・OS許可ダイアログは提供元に従います。すべての画面サイズ・VoiceOver・長いデバイス名の組み合わせを網羅していません。
7. **未提供機能**：VST2/AU、Intelプラグイン、サラウンド、Windows ASIO互換、本家の全機能互換はありません。v1は品質検証済みの一般公開版を意味するものではありません。

## 改善提案（優先順）

- **デバイス別チャンネル割り当ての保存**：今はバス単位。デバイスを切り替えると存在しないチャンネル番号が残り得るため、UIDとバスの組み合わせで保存し、有効範囲を提示する。
- **診断画面**：ドロップ／アンダーフロー／プラグイン遅延超過／録音リング不足を数値化し、実測レイテンシと理論ブロック時間を区別して表示。
- **ルーティングとEQのシーン保存**：配信・通話・DAW・ヘッドフォン等のセットを比較・復元。大幅な切替は短いクロスフェードでクリックノイズを抑える。
- **ミニミキサーの操作対象追従**：ホットキーの対象バスが非表示設定でも、そのバスだけ一時表示。表示秒数も設定可能にする。
- **長時間録音／再生**：再生のストリーミング化、録音ファイル分割、ディスク残量警告、書き込み失敗や取りこぼしの通知。
- **プラグイン互換性と監視**：スキャン失敗の隔離リスト、CPU・遅延の表示、復旧ポリシー、workerの資源制限を検討。
- **公開工程**：クリーン環境でのCI、固定依存のSBOM、署名・公証・pkg導入とアンインストールの検証、macOS各版の実機マトリクス。
