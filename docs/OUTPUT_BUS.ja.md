# 出力バスの処理順とプレビュー（v1 build 3）

既定は **PRE INSERTS → FADER / MODE → POST INSERTS → EQ → LIMIT**。EQで増幅したピークを最後のリミッターで制限する構成です。実フェーダーは画面下部に固定し、処理位置を横線のFADERで表示します。Muteは最終出力でも適用されるため、後段プラグインの残響もミュートできます。

MASTER SECTION右上の上下矢印、またはオーディオ設定の「信号順序」から全バス共通の順序を設定します。EQ Positionは他の4段の前後5点から選択できます。PRE／FADER／POSTの関係は維持し、EQとLIMITは上下矢印でも移動できます。変更時はエンジンを一時停止します。EQやプラグインをLIMITの後に置いた場合、最終出力がそのCeilingを超える可能性があります。

- EQボタン：左クリックでON/OFF、右クリックで編集。下のカーブをクリックしても編集できます。無効時はカーブを灰色で表示します。
- PRE／POST INSERTS：見出しにそれぞれの個数を表示。各枠は2段分を表示し、3個以上は枠内スクロールで移動します。見出しの左クリックはバス全体のインサートチェーンON/OFF、右クリックはラック設定。個別項目は左クリックでそのエフェクトのON/OFF、右クリックでそのエフェクトのGUIを開きます。青色は個別に有効な状態で、チェーン全体が無効なら実処理はバイパスします。
- LIMIT：左クリックでON/OFF、右クリックでThreshold／Ceilingを設定。既定はThreshold約−0.9 dBFS、Ceiling 0 dBFS。旧版のソフトニー特性を維持し、先読み・追加遅延はありません。実際の制限量からボタンを赤く点滅させ、短いピークを視認できるよう約150 ms保持します。True Peakリミッターではありません。
- 上部のA1〜B2ボタン：直下のバスの出力デバイスを選択。現在のデバイス名をボタンの下に2行まで表示します。

検証：既存の音声回帰テスト一式、5点すべてのEQ位置と保存値の往復、PRE/FADER/POSTの制約、実ミキサーの処理順による信号変化、LimiterのCeiling・バイパス・表示保持解除を確認。実画面でレイアウトの収まり、右クリックLIMIT設定、EQカーブからの編集、更新後のエンジン起動を確認しました。任意の市販エフェクトすべてのGUI操作を網羅したものではありません。
