# 出力バスの処理順とプレビュー（v1 build 5）

既定は **PRE INSERTS → FADER / MODE → POST INSERTS → EQ → LIMIT**。EQで増幅したピークを最後のリミッターで制限する構成です。実フェーダーは画面下部に固定し、処理位置を横線のFADERで表示します。Muteは最終出力でも適用されるため、後段プラグインの残響もミュートできます。

MASTER SECTION右上の上下矢印、またはオーディオ設定の「信号順序」からEQ位置を設定します。選択肢はINSERT群の前／INSERT群の後／LIMITの前／LIMITの後です。INSERT群の後とLIMITの前は同じ信号位置で、既定はLIMITの前です。PRE → FADER → POST → LIMITは固定です。以前のINSERT群内部のEQ位置は群の外へ移行します。画面のEQ枠も実際の順序へ移動します。変更時はエンジンを一時停止します。LIMITの後のEQで増幅すると、そのCeilingを超える可能性があります。

- EQボタン：左クリックでON/OFF、右クリックで編集。下のカーブをクリックしても編集できます。無効時はカーブを灰色で表示します。
- INSERT：PRE／POSTを1つの枠にまとめ、見出しに合計個数を表示。通常3個を表示し、追加分は枠内スクロールで移動します。POSTがある場合はFADER境界線を枠内に入れて表示領域を12 pt延長し、POSTがないバスの境界線下端と揃えます。POSTがない場合はPOST表示を省略します。見出しの左クリックはバス全体のインサートチェーンON/OFF、右クリックはラック設定。個別項目は左クリックでそのエフェクトのON/OFF、右クリックでそのエフェクトのGUIを開きます。青色は個別に有効な状態で、チェーン全体が無効なら実処理はバイパスします。
- LIMIT：左クリックでON/OFF、右クリックでThreshold／Ceilingを設定。既定はThreshold約−0.9 dBFS、Ceiling 0 dBFS。旧版のソフトニー特性を維持し、先読み・追加遅延はありません。実際の制限量からボタンを赤く点滅させ、短いピークを視認できるよう約150 ms保持します。True Peakリミッターではありません。
- 上部のA1〜B2ボタン：直下のバスの出力デバイスを選択。現在のデバイス名をボタンの下に2行まで表示します。

検証：既存の音声回帰テスト一式、EQの4選択肢と保存値の往復、PRE/FADER/POSTの制約、実ミキサーの処理順による信号変化、LimiterのCeiling・バイパス・表示保持解除を確認。実画面でレイアウトの収まり、右クリックLIMIT設定、EQカーブからの編集、更新後のエンジン起動を確認しました。任意の市販エフェクトすべてのGUI操作を網羅したものではありません。

## リミッターの先読み（build 9）

LIMITを右クリックするとLookaheadをOFF／1／3／5／10／20 msから選べます。従来設定・初期値はOFFで、既存のサンプルごとのソフトニー波形制限を維持します。ONでは指定時間分のステレオ音声を固定長リングで遅延し、出力サンプルから先読み範囲の最大ピークまでを左右連動で検出します。ThresholdとCeilingで求めたゲインを両チャンネルへ共通適用し、ゲイン回復には50 msのリリースを使います。持続した強い信号を波形ごとに潰す歪みを抑えやすい一方、急なゲイン変化や音量の揺れがなくなる保証はありません。オーバーサンプリング／True Peak処理ではなく、Ceilingはサンプルピークの上限です。後段EQやプラグインがあれば最終ピークは再上昇し得ます。

追加遅延はfloor(SR×ms／1000)サンプルで、48 kHz・5 msなら240サンプルです。既存の経路・出力バス間補正へ含めます。出力バス間補正ONなら他バスも整列のため遅れ、OFFなら独立した出力への追加補正は行いません。設定切替・ON/OFF時は履歴を初期化するため短い途切れがあり得ます。固定長の音声リングと単調キューを事前確保し、音声コールバック内でロック・メモリ確保やFFT処理は追加しません。

参考：[FabFilterの先読み設定の説明](https://www.fabfilter.com/help/pro-l/using/advancedsettings)。先読み時間は音色・歪み・遅延のトレードオフであり、単に長いほど高精度になるという意味ではありません。実装にFabFilterのコードは使用していません。

Build 11ではINSERTプレビューの横幅をスクロール表示領域に固定しました。長いPOST名がPRE行やFADER境界線を押し広げる問題を修正し、長い名前は末尾を省略、全文はツールチップで確認できます。縦スクロールは維持し、細いバスでは幅を消費するスクロールバーを非表示にしています。POSTあり／なしの全体高さ86 ptと、PRE 2個＋POST 1個を収める64 ptの表示領域は維持します。
