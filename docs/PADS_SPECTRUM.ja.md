# 入力PAD・スペクトラム表示（v1 build 5）

物理入力1〜3のPAD見出しでモードを選択します。PADの右クリックでも次へ切り替えます。ダブルクリックは中央、中央付近はスナップします。モードごとの値は保存され、領域の大きさは共通です。通常PANの独立した下段表示は、このPAD内へ統合しました。VAIO/AUXの通常PANは従来どおりです。

- PAN：左右バランス。
- INTELLIPAN：横は左右バランス、縦は低域／高域のシェルフによる最大±6 dBの音色傾斜。Bright／DarkはHPF／LPFではありません。旧実装で未処理だった縦方向を実装しました。
- MODULATION：ステレオ・コーラス。横は0.1〜4.9 Hzの速度、縦は中央からの距離で深さとウェット量。中央はドライです。効果の遅延音は演出のため補正対象にしません。
- PITCH：横は±12半音、縦は中央100%から上下端25%までウェット比。軽量な2ヘッドの時間領域方式。見出しメニューでLow Latency／Smoothを選びます。公称遅延は約10 ms／20 ms＋2サンプルで、経路補正に加算します。実際の読み取り位置は時間変動し、位相が厳密に一致する補正ではありません。フォルマント保持機能はなく、大幅な変更・複雑な音楽では揺れや粒状感があります。
- FORMANT (EXP)：横は共鳴帯域の0.5〜2倍の移動、縦は共鳴の強さ。500／1500／2500 Hz付近の固定共鳴を弱め、移動先を強調する試験用の母音的音色処理です。ピッチは変えません。音声のフォルマントを推定して再合成する厳密な方式ではありません。追加バッファ遅延はありませんが、フィルターの位相変化はあります。

EQ編集画面のSPECTRUMスイッチでスペアナをON/OFFにします。既定はOFF。FFT 8192、Hann窓、平均300 ms、1/6 oct平滑化、+3.01 dB/octの表示傾斜が既定です。1/fの**パワー**スペクトル（ピンクノイズ）が概ね平らになる傾斜です。1/fの振幅スペクトルとは区別してください。SPANの既定4.5 dB/octとは異なります。音声処理のEQ設定には影響しません。

解析点は設定したEQの直後です。EQがOFFでも同じ位置を測ります。左右はパワー平均し、逆相音でも相殺しません。FFTと履歴処理は専用のutilityキュー、描画は最大20 fps。音声コールバックでは選択したバスだけを固定長リングへコピーし、解析OFF／編集画面を閉じたときはコピーも解析タイマーも停止します。遅れた表示履歴は破棄して仕事量を制限します。録音リールは動作中のみ15 fps、リミッターの点滅も制限時のみ更新します。

検証はPADの中央の透過性、極端な設定・複数サンプルレートでの有限性、ピッチのオクターブ比、ステレオ逆相のFFT、1/f表示傾斜、解析OFF時のコピー停止と既存音声回帰テストを含みます。実際の声・全プラグイン・長時間の全デバイス組合せを網羅するものではありません。

参考：[Voxengo spectrum analysis FAQ](https://www.voxengo.com/qna/spectrum-analysis-28/)。実装は独自のDSPで、SPANのコードを使用していません。
