# 入力PADとEQスペアナ

物理入力のPADはPAN／COLOR PAN／MODULATION／PITCH／FORMANT (EXP)を切り替えます。選択メニューまたは右クリックで切り替え、同じ領域で編集します。通常PANは中央付近のスナップとダブルクリックの中央復帰に対応します。INTELLIPANのBright/Darkは音色用シェルフで、単純なHPF/LPFではありません。

MODULATIONはコーラス系の変調、PITCHは簡易ピッチ変更です。FORMANTは固定共鳴を動かす試験的な別PADで、厳密な声道推定・ピッチ独立フォルマント変換ではありません。声が変わる効果を試す用途です。商用ボイスチェンジャーと同じ品質を保証しません。

出力EQはEQボタン右クリックかカーブをクリックして開きます。スペアナはON/OFF式でEQカーブと周波数軸を共有します。左軸はEQゲイン、右軸はスペクトラム表示。FFTサイズ（2048–16384）、窓、平均時間、表示fps、傾きを設定できます。既定の約3.01 dB/oct傾きはピンクノイズ（1/f電力密度）を概ね平坦に見るための表示補正です。音声へEQを掛ける設定ではありません。

Fastモードは小さいFFTと短い平均・高い更新頻度で応答を優先します。大きいFFTは周波数分解能と引換えに時間方向をぼかし、平均時間も反応へ影響します。TopとRangeで表示dB範囲を選択し、Autoで現在のピークへ一度だけ合わせられます。

スペアナONでもEQエディターを閉じている間は解析用収集・FFT・描画を停止します。FFTは音声コールバックではなく解析側で実行し、可視化は上限fpsと独立更新で負荷を抑えます。高解像度／高fpsは低負荷モードよりCPUを使うため、音切れがある場合は下げてください。
